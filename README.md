# 會幕 3D 教學工具

出埃及記 25-31、35-40 的立體模型。

**線上版**：https://bbshen1995-hash.github.io/tabernacle-3d/

## 這是什麼

每一件器具、每一個空間、每一個在裡面工作的人，點下去都有一段完整的說明，
講它是什麼、為什麼要這樣做、做來幹嘛、想表達什麼。說明底下的「經文註解」按鈕，
列出那一段的經文章節。

三十張說明牌、七個分區、七段跨器具的主線、十六站導覽。
模型可以一層一層剖開，從海狗皮蓋子一路掀到約櫃。

## 幾件事先說

模型上有些大小是經文沒有給、為了畫得出來才定的。哪些數字可以直接引用、
哪些只能說「推算大約是」，全部寫在底下的「這個模型哪裡是推測」那一頁。
要引用數字之前請先看那一頁。

凡是經文沒有明說、屬於後世理解的說法，正文裡都會帶一句「後來的人這樣理解」。

模型裡五個人的身高一律用 170 公分。經文沒有記載任何人的身高，
這個數字純粹是為了讓人看得出器具有多大才定的。

## 怎麼用

- 拖曳轉動，滾輪往游標指到的地方縮放，雙擊把那一點拉到眼前
- 右上角的圖層面板由外而內排，可以一層一層掀掉
- 左欄兩個分頁：器具與空間逐件看，信仰引導是串起來才看得到的主線
- 「投影」按鈕把整組字級跳一階，課堂投影時後排看得到
- 手機直式可用，左欄改成抽屜

## 技術

單一 HTML 檔，three.js、樣式、資料、程式全部內嵌，不需要伺服器也不需要網路。
地面與天空是程序生成的，沒有外部圖檔。1 單位 = 1 肘，以 45 公分概算。
